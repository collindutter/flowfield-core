---
title: Coordinator Chat
description: Plan work and capture tasks beside the board.
---

Coordinator Chat is the conversation beside your project's board. Discuss an outcome,
ask it to capture and prepare tasks, or reconcile saved project answers. Task links open
the same feeds you use for questions and review.

## Start planning

Install and authenticate [Codex](/integrations/codex), including the managed ACP runtime.
Add an existing project using **Add project → Choose directory** or `flowfield project init`.
In Coordinator Chat, choose a model and reasoning effort beside the input, then save.
Local uses the service host’s tools, credentials and native harness configuration automatically.
Worker delivery branches, setup and checks can be configured later. Built-in chat supplies
its own MCP connection; `flowfield integration connect codex` is only for standalone sessions.

Write your message and select **Send** (or press Command/Ctrl+Enter). Opening a project
starts no model turn. Send is available once you have saved a model and effort.
The coordinator reads project files using Codex's read-only mode and changes work through
project-scoped Flowfield tools. Code changes belong to task workers. Answer worker questions
and approve exact code results in their task feeds.

Use the model button beside the input to change model or effort. Changes apply to the next
message; a running turn keeps its saved choice. Standalone coding-agent settings are separate.

## Follow and stop

Replies stream into the conversation. Expand **Activity** for public tool activity;
private reasoning is never displayed. One coordinator turn can run per project, independently
of worker slots. You can write your next draft while it runs, then send when it finishes.

**Stop** ends the selected coordinator turn. Saved task changes remain, and task workers
continue independently. If a connection fails, the retained turn explains whether it stopped
or needs recovery. Flowfield never replays an interrupted prompt. If native cleanup could not
be confirmed, stop the remaining coordinator process on the host before choosing
**Confirm coordinator stopped**.

## Continue later

Each project has one ongoing coordinator conversation. Messages, public output and turn settings
are saved by the service. Older messages load on demand. Long output is bounded and omissions
are marked. Tool activity shows names, status and available commands or paths.

Each turn starts a fresh native session with up to eight recent exchanges within a bounded
context budget, plus tools for reading current project state. This is application conversation
history, not a resumed native session. Record important ongoing intent in tasks and decisions.

Resize the chat and work panes on a wide screen. On narrow screens, switch between
**Coordinator** and **Work**; switching preserves the current draft.
