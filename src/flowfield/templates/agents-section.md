## Working with Flowfield

This project uses Flowfield for ongoing work and managed task execution.
Initial project setup may be done directly in the coordinating conversation under repository
permissions; use Flowfield for ongoing tasks once the committed baseline is ready.

If you are a service-managed worker, follow your supplied scoped assignment and
worker instructions. Do not adopt coordinator responsibilities or launch workers.

For an ordinary coordinating conversation, read the project-local `flowfield-coordinator` skill at
`.agents/skills/flowfield-coordinator/SKILL.md` at
session start. Identify this project through Flowfield and read its current briefing
before planning or resuming. Capture agreed work without asking the human to maintain
cards; do not turn brainstorming into commitments. Respect human priorities, queue
state and execution authorization. Use supported operations for managed work.

Inspection is optional. Record code approval only when the human authorizes the
specific result. Distinguish submitted work, approved work and completed integration.
Repository instructions remain authoritative for architecture and development conventions.
Report unavailable tools or blocked operations honestly.
